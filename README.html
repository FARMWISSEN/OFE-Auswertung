# OFE Auswertung - QGIS Plugin für die Auswertung von On-Farm-Experimenten Das OFE Planung Plugin ist ein Plugin des OFE-Werkzeugkastens der OG SNaPwürZ. Es unterstützt in QGIS bei der Auswertung von On-Farm-Experimenten und dies von Großparzellenversuche bis zu Kleinparzellen. 🚧 **Hinweis: MVP & Work in Progress** Dies ist eine frühe Version (Minimum Viable Product) des Projekts. Die Kernfunktionen sind implementiert, aber die Entwicklung ist noch im Gange. * **Stabilität:** Es können unentdeckte Bugs existieren. * **Änderungen:** Breaking Changes an APIs und Datenstrukturen sind jederzeit möglich. ## Praktische Anwendung Zur praktischen Anwendung, nach dem Aufruf des Plugins müssen die auszuwertenden Daten definiert werden. Jede einzelne Auswahl muss jeweils mit „Bestätigen“ übernommen werden, danach sind die nächsten Eingaben möglich. Nötige Eingaben sind (in der Reihenfolge): Datensatz, Zielgröße, Blockfaktor/Wiederholung, Anzahl der Faktoren (1 oder 2) sowie der konkrete Faktor 1 oder wenn gewünscht Faktor 2. ## 🧩 Installation toDo
