# OFE Auswertung - QGIS Plugin für die Auswertung von On-Farm-Experimenten Das OFE Planung Plugin ist ein Plugin des OFE-Werkzeugkastens der OG SNaPwürZ. Es unterstützt in QGIS bei der Auswertung von On-Farm-Experimenten und dies von Großparzellenversuche bis zu Kleinparzellen. 🚧 **Hinweis: MVP & Work in Progress** Dies ist eine frühe Version (Minimum Viable Product) des Projekts. Die Kernfunktionen sind implementiert, aber die Entwicklung ist noch im Gange. * **Stabilität:** Es können unentdeckte Bugs existieren. * **Änderungen:** Breaking Changes an APIs und Datenstrukturen sind jederzeit möglich. ## 🧩 Installation
